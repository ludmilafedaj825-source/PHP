Контрольні запитання
1) В чому принципова різниця між індексованими та асоціативними масивами в PHP? Наведіть фрагменти коду з прикладами.
Головна відмінність це те, що в індексованому масиві кожен елемент має свій порядковий номер(індекс), що починається з 0. Звернення відбувається за індексом.
Приклад індексованого масиву:
$names = ['Piter', 'Alex', 'Alisa'];
Асоціативний масив має текстові пари ключ-значення. Звертається не за індексом, а за ключем.
Приклад асоціативного масиву:
$task = [
        'id'=> 1,
        'title' => 'Виконати лабораторну роботу №5',
        'priority' => 'High',
        'is_completed'=> true
    ];
2) Які ключові компоненти містить цикл foreach? Чому його використання для масивів є кращим за цикл for?
Ключові компоненти циклу foreach - масив, що перебирається, слово "as" та змінна-псевдонім для елемента, який нам потрібен.
Його використання для масивів є кращим, тому що він означає "для кожного", тобто він проходиться по всьому масиву від першого до останнього, не потрібен лічильник, немає ризику нескінченного циклу, а також можливості вийти за межі масиву та його можна використовувати для асоціативного масиву.
3) Що буде, якщо у foreach звернутися до ключа, якого не існує в асоціативному масиві (наприклад, $task['deadline'])?
Виведеться Warning: Undefined array key "deadline", проте сам скрипт не зупиниться.
4) Для чого ми використовуємо альтернативний синтаксис endforeach; замість фігурних дужок } в HTML-шаблонах?
PHP та HTML пишуться в одному документі і фігурна дужка серед великої кількості HTML-тегів може просто загубитися, а з  альтернативний синтаксисом endforeach одразу зрозуміло, яка дія закінчується.
5) Наведіть мінімум 3 приклади корисних вбудованих функцій PHP для роботи з масивами (наприклад, для кількості, сортування тощо) та коротко опишіть їх.
count($array) - рахує та повертає кількість елементів у масиві.
sort($array) - сортує числа за зростанням або рядки за алфавітом, проте він знищує ключі.
ksort($array) - сортує масив за ключами, а не за значеннями.
