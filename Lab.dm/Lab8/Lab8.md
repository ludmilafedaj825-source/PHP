# Контрольні запитання

1) Що таке enctype="multipart/form-data" і чому його обов’язково треба використовувати в тегу form для файлів?

Це атрибут HTML-форми, який визначає спосіб кодування даних перед їх відправкою на сервер. Він використовується, щоб браузер міг відправляти бінарні дані на сервер. Без нього браузер надсилає лише назву файлу текстом, а байти зображення не будуть передані.

2) Які ключі завжди присутні в масиві для конкретного файлу в $_FILES? Опишіть призначення ключа tmp_name.

Він має 5 стандартних ключів-характеристик: name (оригінальна назва файлу), type (тип файлу), size (розмір файлу), error (код помилок завантаження), tmp_name(тимчасовий шлях).
Ключ tmp_name містить шлях до тимчасового файлу на сервері, куди одразу PHP поклав завантажений файл. Саме звідси файл потім завантажують у потрібну папку.

3) Чому файли не зберігаються одразу у вашій папці проєкту після натискання Submit, а містяться в тимчасових директоріях операційної системи (tmp_name)?

Тому що файл ще не є перевіреним. Він може бути завеликим, неправильного формату або бути шкідливим.

4) Для чого ми використовуємо функцію move_uploaded_file()? Чому не можна просто скопіювати файл звичайною функцією copy() без перевірок безпеки?

Вона переміщує файл із тимчасової папки у потрібне місце і при цьому перевіряє, що файл справді був завантажений через HTTP POST. Функція copy() цього не перевіряє, шлях до файлу могли б підмінити і тоді можна було б мати доступ до системних файлів сервера.

5) Які потенційні загрози несе дозвіл користувачам “завантажувати будь-що” на сервер (без перевірки розширення чи типу)?

Шкідливі файли та віруси, дуже великі файли за розміром, що можуть забити диск, файл з однаковою назвою може змінити вже існуючий, файли `.html` чи `.svg` можуть містити шкідливий JS (XSS-атака), завантаження шкідливого php-скрипта, який можна потім відкрити у браузері і виконувати на сервері.
