function formatTitle($text, $maxLength = 20)
{
    return strlen($text) > $maxLength ? substr($text, 0, $maxLength)."..." : $text;
}

function getCurrentGreeting(){
    $hour = date('H');
    if($hour>=6 && $hour<12){
        return "Доброго ранку";
    }
    elseif($hour>=12 && $hour<18){
        return "Добрий день";
    }
    elseif($hour>=18 && $hour<24){
        return "Добрий вечір";
    }
    else{
        return "Доброї ночі";
    }
}

Власні функції допомагають його дотримуватися тим, що вони створюються один раз в єдиному унікальному екземплярі, а потім викликається багато разів.
2)Що таке аргументи функції та що таке параметри за замовчуванням? Наведіть приклад з коду.
Параметри це змінні оголошені в функції, а параметр за замовчуванням це те, що використовується, якщо в функцію не було передано аргументів, а аргументи це значення, які передаються при виклику функції.

3)Що станеться, якщо у функції не написати конструкцію return, але спробувати присвоїти результат її виклику в змінну x ($x = myFunc())? Яке значення буде в $x?
Сама функція виконається, проте вона нічого не поверне у відповідь. Значення $x буде NULL
4)Що таке “область видимості” (scope) змінної? Чи можна у тілі функції звернутись до $taskTitle, створеної за межами цієї функції, без ключового слова global?
Область видимості це те, де використання змінної доступно. Змінна створена у середині функції є локальна і доступна в ній, а змінна, що поза межами функції не доступна для використання, тобто її не видно. Не можна, тому що без ключового слова global, ця функція буде вважатися PHP невідомою новою локальною змінною і видасть відповідне попередження. 
5)Для чого призначена вбудована функція substr() і які вона умовно приймає аргументи?
Вона призначена для обрізання рядка, якщо він перевищує вказане обмеження в довжині, тобто повертає частину рядка. Приймає аргументи: рядок, із якого починають, потім початкова позиція, і кінцева позиція(тобто до якого символу буде збережений рядок)
