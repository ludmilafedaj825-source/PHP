#Контрольні запитання:

1) Назвіть 3 ключові відмінності між HTTP-методами GET та POST під час передачі даних з форми.

Метод GET передає дані в URL, а метод POST передає дані приховано в тілі запиту, для подальшої обробки. Також відмінність у пам'яті: GET підходить для малого обсягу даних, у той час як POST майже не має обмежень. GET лише отримує дані, а POST відправляє дані на створення або зміни.

2) Вкажіть, в яких ситуаціях передача даних методом GET (відкритим текстом в URL) є прийнятною, і чому не можна передавати таким чином паролі.

GET доречний для пошуку, сортування, коли дані є не секретними. Не можна передавати паролі. тому що їх видно в адресному рядку, і вони залишаються в історії браузера та в логах сервера.

3)За що відповідає HTML-атрибут action у тегу <form>?

Вказує, на яку сторінку відправляються дані форми.

4) За яким критерієм PHP асоціюватиме дані з форми з ключами у масиві $_POST (які HTML атрибути тут вирішальні)?

PHP формує ключі масиву $_POST за HTML-атрибутом name елементів форми. Значення атрибута name стає ключем, а введене користувачем значення (або value обраного пункту в select) стає значенням. 

5) Назвіть призначення функції var_dump() та тегу <pre>. Чи використовується цей код у продуктовому (Production) середовищі для реальних клієнтів?

var_dump() показує тип і значення змінної, щоб подивитися, чи дійшли дані до сервера.
<pre> зберігає відступи і переноси рядків, щоб вивід було зручно читати. У продуктовому середовищі не використовується, тому що розкриває внутрішні дані програми, тому потрібна розробнику лише для перевірки.
